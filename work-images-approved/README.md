## 图片标准（固定）

| 项 | 标准 |
|---|---|
| 尺寸 | 1200 × 900 px（4:3） |
| 格式 | JPG / WebP |
| 大小 | 100–300 KB |
| 裁剪 | 先保证内容完整，再适配 4:3；禁止切产品/放大模糊/只留纹理局部 |

## 3 秒识别要求（客户第一眼看懂"这是什么项目"）

- **铝型材**：完整型材 / 截面 / 多根型材 / 门窗型材成品（❌ 只有灰色截面纹理不行）
- **PVC 型材**：完整 profile / 截面结构 / 实际应用
- **成品寻源**：产品完整、背景简单、无品牌、无电商感（表达"客户需要这个产品，我帮他找合适方案"）
- 滚塑模具类：车间图可接受（表达"大型模具项目"）
